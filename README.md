# Zoo Animal (Java)

Practice project: my Course 1 end assignment from the Amazon Junior Software Developer Professional Certification (Java).

A console menu app demonstrating OOP: an abstract `Animal` class, the `Eat`, `Walk` and `Swim` interfaces, and the `Tiger`, `Dolphin` and `Penguin` subclasses.

## Run

```bash
cd src
javac *.java
java Main
```
